# NICCA Connect+ v7 Modern UI

Versi ini mempertahankan Firebase Authentication, Firestore realtime chat, login ID + password, multi-user, warna member, fixed header dan fixed composer.

Perubahan visual:
- Logo NICCA pada login dan header
- Tema hijau/putih seperti mockup
- General Chat header dan status user
- Avatar otomatis berdasarkan nama pengirim
- Bubble chat modern dengan warna konsisten per UID
- Tampilan fullscreen/responsif untuk HP
- Favicon dan manifest dasar untuk PWA/app icon

Untuk update GitHub Pages, ganti file index.html, style.css, app.js dan upload juga:
nicca-logo.png, icon-192.png, icon-512.png, manifest.webmanifest.
